# @piharness/pet-circle

## 简介

圆形桌面宠物：一颗圆滚滚的果冻小球，跟随 Pi 的工作状态做出不同动作和表演。体积很小。

在 Pi-Harness 打开 设置 → 资源市场，找到这个桌宠并安装，然后在桌宠设置里选择它。

## About

Circle desktop pet: a round jelly ball that reacts to what Pi is doing with live motion and short performances. Very small download.

In Pi-Harness, open Settings → Resource Market, install this pet, then pick it in the desktop pet settings.
