# @piharness/theme-ming-snow

## 简介

明朝雪宫主题：深色界面，雪中宫殿背景和雪中少女立绘，配木质边框、羊皮纸和朱砂按钮等古风装饰。

在 Pi-Harness 打开 设置 → 资源市场，找到这个主题并安装，然后在外观设置里选择它。卸载后会回到默认外观。

## About

Ming Snow Palace theme: a dark workspace with a snowy palace and a snow maiden portrait, framed by Ming-style wood, parchment, and cinnabar decorations.

In Pi-Harness, open Settings → Resource Market, install this theme, then pick it in the appearance settings. Uninstalling returns you to the default look.
