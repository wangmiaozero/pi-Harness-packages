# @piharness/theme-deepseek

## 简介

DeepSeek 角色主题：一次包含 4 种外观（DeepSeek、DeepSeek Pro、工作模式海报壁纸、深梦壁纸），蓝色强调色，附带开场动画和角色语音。

在 Pi-Harness 打开 设置 → 资源市场，找到这个主题并安装，然后在外观设置里选择它。卸载后会回到默认外观。

## About

DeepSeek character theme with 4 looks (DeepSeek, DeepSeek Pro, a Work Mode poster wallpaper, and a Deep Dream wallpaper), blue accents, plus a startup animation with voice lines.

In Pi-Harness, open Settings → Resource Market, install this theme, then pick it in the appearance settings. Uninstalling returns you to the default look.
