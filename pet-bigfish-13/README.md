# @piharness/pet-bigfish-13

## 简介

大肥鱼动作包 13：给大肥鱼桌宠添加 10 个新动作——吃腊八粥、吃年糕、吃青团、吃汤圆、吃糖葫芦、吃晚餐、吃午餐、吃西瓜、吃早餐、吃长寿面。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 13: adds 10 new actions to the BigFish pet, including meals and traditional festival foods. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
