# @piharness/theme-zhang-juzheng

## 简介

张居正主题：深色界面，雪中红墙宫城背景和张居正人物立绘，配书法卷轴、雪中横幅标题栏和古风装饰。

在 Pi-Harness 打开 设置 → 资源市场，找到这个主题并安装，然后在外观设置里选择它。卸载后会回到默认外观。

## About

Zhang Juzheng theme: a dark workspace with a snowy red-walled palace, a Zhang Juzheng portrait, calligraphy scrolls, a snowy title banner, and Ming-style decorations.

In Pi-Harness, open Settings → Resource Market, install this theme, then pick it in the appearance settings. Uninstalling returns you to the default look.
