# @piharness/pet-bigfish-2

## 简介

大肥鱼动作包 2：给大肥鱼桌宠添加 10 个新动作——安静眨眼、抱尾打盹、抱尾举牌、抱尾撒娇、擦汗歇息、操作检查、侧躲探头、高高举牌、乖巧鞠躬、挥手跳跃鞠躬。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 2: adds 10 new actions to the BigFish pet, including calm idles, naps, sign holding, and bows. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
