# @piharness/pet-jelly

## 简介

软糖桌面宠物：一颗会弹会晃的果冻小软糖，跟随 Pi 的工作状态做出不同动作和表演。体积很小。

在 Pi-Harness 打开 设置 → 资源市场，找到这个桌宠并安装，然后在桌宠设置里选择它。

## About

Jelly desktop pet: a bouncy little jelly that reacts to what Pi is doing with live motion and short performances. Very small download.

In Pi-Harness, open Settings → Resource Market, install this pet, then pick it in the desktop pet settings.
