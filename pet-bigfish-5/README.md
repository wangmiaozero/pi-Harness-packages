# @piharness/pet-bigfish-5

## 简介

大肥鱼动作包 5：给大肥鱼桌宠添加 10 个新动作——把选择递给你、贝壳小把戏、便签打字、擦掉重画、擦干净再举牌、擦亮尾巴、草稿演算、测试巡检、齿轮咔哒转、打包小行李箱。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 5: adds 10 new actions to the BigFish pet, including notes, sketches, test rounds, gears, and packing up. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
