# @piharness/theme-gemini

## 简介

Gemini 角色主题：深色界面配 Gemini 风格的角色立绘，紫色强调色，附带开场动画和角色语音。

在 Pi-Harness 打开 设置 → 资源市场，找到这个主题并安装，然后在外观设置里选择它。卸载后会回到默认外观。

## About

Gemini character theme: a dark workspace with a Gemini-styled character portrait, purple accents, and a startup animation with voice lines.

In Pi-Harness, open Settings → Resource Market, install this theme, then pick it in the appearance settings. Uninstalling returns you to the default look.
