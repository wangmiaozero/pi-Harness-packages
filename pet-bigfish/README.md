# @piharness/pet-bigfish

## 简介

大肥鱼桌面宠物：鲸鱼尾巴女仆，在桌面上陪你写代码，会根据 Pi 的工作状态（思考、运行、成功、出错等）切换动作。这是基础包，更多动作可另装 pet-bigfish-2 到 pet-bigfish-20。

在 Pi-Harness 打开 设置 → 资源市场，找到这个桌宠并安装，然后在桌宠设置里选择它。

## About

BigFish desktop pet: a whale-tailed maid who keeps you company on the desktop and changes poses with what Pi is doing (thinking, running, success, error, and more). This is the base pack; more actions come in pet-bigfish-2 to pet-bigfish-20.

In Pi-Harness, open Settings → Resource Market, install this pet, then pick it in the desktop pet settings.
