# @piharness/pet-bigfish-9

## 简介

大肥鱼动作包 9：给大肥鱼桌宠添加 10 个新动作——轻摆提示铃、清理后再试、上发条小鲸鱼、深吸气再开工、书堆找答案、梳梳尾巴边、算盘推演、听听贝壳、挽袖开工、望远镜看网页。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 9: adds 10 new actions to the BigFish pet, including reminder bells, retries, books, an abacus, and a telescope. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
