# @piharness/pet-bigfish-17

## 简介

大肥鱼动作包 17：给大肥鱼桌宠添加 10 个新动作——轻快记录、轻快摇摆舞、三球抛接、深度思考碎碎念、是啊，吃什么、收红包、涮火锅、碎碎念-擦桌碎碎念、碎碎念-对屏碎碎念、碎碎念-发呆碎碎念。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 17: adds 10 new actions to the BigFish pet, including dancing, juggling, mumbling to herself, red envelopes, and hot pot. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
