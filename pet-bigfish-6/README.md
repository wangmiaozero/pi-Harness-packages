# @piharness/pet-bigfish-6

## 简介

大肥鱼动作包 6：给大肥鱼桌宠添加 10 个新动作——戴眼镜排查、弹出式请帖、递来确认信、调色画画、多任务分篮、翻到等你这一页、放大镜找线索、分你半块饼干、扶好眼镜再写、给尾巴铺小窝。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 6: adds 10 new actions to the BigFish pet, including debugging with glasses, letters, painting, and searching for clues. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
