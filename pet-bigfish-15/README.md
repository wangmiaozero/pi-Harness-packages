# @piharness/pet-bigfish-15

## 简介

大肥鱼动作包 15：给大肥鱼桌宠添加 10 个新动作——点击回应-害羞惊讶、点击回应-开心跃动、东张西望、动物环绕、堆雪人、放风筝、放河灯、放孔明灯、放烟花、蝴蝶蜜蜂环绕头顶开花。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 15: adds 10 new actions to the BigFish pet, including click reactions, snowmen, kites, lanterns, and fireworks. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
