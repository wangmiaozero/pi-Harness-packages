# @piharness/pet-bigfish-19

## 简介

大肥鱼动作包 19：给大肥鱼桌宠添加 11 个新动作——写福字、摇扇纳凉、用鲸鱼尾巴拍打地面、优雅女仆舞、悠闲哼歌、余额-袋空如洗、余额-分文不剩、余额-金袋叮当、余额-钱袋满溢、余额-钱袋如常、余额-数金皱眉。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 19: adds 11 new actions to the BigFish pet, including calligraphy, fanning, maid dance, humming, and wallet-balance moods. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
