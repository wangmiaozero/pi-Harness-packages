# @piharness/pet-bigfish-20

## 简介

大肥鱼动作包 20：给大肥鱼桌宠添加 11 个新动作——原地蹲下玩玩具汽车、原地敲击桌面互动、原地跳跃抓碎头顶物品、原地小憩沉眠、原地重力下蹲压缩、原地专心玩魔方、照镜子、整体换装试色、中秋赏月吃月饼、装点圣诞树、左转奔跑。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 20: adds 11 new actions to the BigFish pet, including toy cars, Rubik's cubes, mirrors, outfit changes, mooncakes, and a Christmas tree. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
