# @piharness/pet-bigfish-11

## 简介

大肥鱼动作包 11：给大肥鱼桌宠添加 11 个新动作——折一只纸鱼、整理便签、整理交付包、整理鲸鱼徽章、织一条鲸鱼围巾、值班鲸鱼盖章、纸飞机送信、纸花庆祝、纸鱼小船队、转椅半圈、追一颗泡泡。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 11: adds 11 new actions to the BigFish pet, including paper fish, sticky notes, badges, paper planes, and bubbles. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
