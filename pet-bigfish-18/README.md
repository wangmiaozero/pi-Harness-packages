# @piharness/pet-bigfish-18

## 简介

大肥鱼动作包 18：给大肥鱼桌宠添加 10 个新动作——讨糖南瓜灯、踢毽子、偷吃零食被抓住、玩水枪、玩游戏气急败坏、舞狮头、下五子棋、小幅度原地360度旋转展示、小提琴演奏、写代码。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 18: adds 10 new actions to the BigFish pet, including Halloween, shuttlecocks, water guns, lion dance, gomoku, violin, and coding. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
