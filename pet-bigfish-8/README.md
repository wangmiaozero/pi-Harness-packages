# @piharness/pet-bigfish-8

## 简介

大肥鱼动作包 8：给大肥鱼桌宠添加 10 个新动作——口袋里掏出小牌、困惑地图、牌子拿反了、牌子太大了、泡泡落在头上、拼出等候牌、拼起思路、启动小控制台、气球托起牌、铅笔修改。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 8: adds 10 new actions to the BigFish pet, including sign mix-ups, bubbles, puzzles, consoles, and balloons. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
