# @piharness/pet-triangle

## 简介

三角桌面宠物：一块三角形的果冻，跟随 Pi 的工作状态做出不同动作和表演。体积很小。

在 Pi-Harness 打开 设置 → 资源市场，找到这个桌宠并安装，然后在桌宠设置里选择它。

## About

Triangle desktop pet: a triangle-shaped jelly that reacts to what Pi is doing with live motion and short performances. Very small download.

In Pi-Harness, open Settings → Resource Market, install this pet, then pick it in the desktop pet settings.
