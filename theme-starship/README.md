# @piharness/theme-starship

## 简介

星舰驾驶舱主题：深色界面，整个工作区被包在星舰驾驶舱框架里，深空背景、雷达和领航员角色，冰蓝色强调色。

在 Pi-Harness 打开 设置 → 资源市场，找到这个主题并安装，然后在外观设置里选择它。卸载后会回到默认外观。

## About

Starship Cockpit theme: a dark workspace framed by a starship cockpit, with a deep-space backdrop, radar, a navigator character, and ice-blue accents.

In Pi-Harness, open Settings → Resource Market, install this theme, then pick it in the appearance settings. Uninstalling returns you to the default look.
