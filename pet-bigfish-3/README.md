# @piharness/pet-bigfish-3

## 简介

大肥鱼动作包 3：给大肥鱼桌宠添加 10 个新动作——挥手招呼、回头看看、交替打字、开心摇尾、踉跄站稳、牌后探头、跑步赶进度、捧杯喝茶、伸懒腰、伸手示意。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 3: adds 10 new actions to the BigFish pet, including greetings, typing, tea breaks, stretching, and hurrying along. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
