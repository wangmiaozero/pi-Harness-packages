# @piharness/pet-bigfish-10

## 简介

大肥鱼动作包 10：给大肥鱼桌宠添加 11 个新动作——尾巴打拍子、尾巴当支架、尾巴先收好、先保住茶杯、小导演带队、小鲸鱼敬礼、小幕布揭牌、阅读夹书签、眨眼稳住节奏、蘸墨写草稿、折叠小横幅。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 10: adds 11 new actions to the BigFish pet, including tail tricks, saluting, banners, bookmarks, and ink drafts. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
