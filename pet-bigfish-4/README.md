# @piharness/pet-bigfish-4

## 简介

大肥鱼动作包 4：给大肥鱼桌宠添加 9 个新动作——手忙脚乱、缩肩反应、叹气放松、完成打勾、小碎步赶工、小跳摇牌、胸前举牌、阅读翻页、左右探头。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 4: adds 9 new actions to the BigFish pet, including flustered moments, sighs, check marks, and reading. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
