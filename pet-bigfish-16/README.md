# @piharness/pet-bigfish-16

## 简介

大肥鱼动作包 16：给大肥鱼桌宠添加 10 个新动作——可爱宅舞、蓝鲸现世、撸猫、萌化小幽灵、女仆屈膝礼仪、螃蟹走路、漂浮踏步、凭空生花、扑克魔术、骑木马。需要先安装大肥鱼（pet-bigfish）。

先安装大肥鱼（pet-bigfish），再在 设置 → 资源市场 安装这个动作包。动作会自动加到同一只大肥鱼上，卸载这个包只移除这些动作。

## About

BigFish action pack 16: adds 10 new actions to the BigFish pet, including dances, a blue whale, cats, a little ghost, and card magic. Requires the BigFish pet (pet-bigfish).

Install BigFish (pet-bigfish) first, then install this pack from Settings → Resource Market. The actions are added to the same BigFish; uninstalling this pack removes only these actions.
